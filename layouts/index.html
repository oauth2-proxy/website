OAuth2 Proxy is a flexible, open-source authentication proxy. Put it in front of your applications to delegate authentication to the identity providers your organization already trusts.

Originally created in 2012, OAuth2 Proxy has been around since before Kubernetes & CNCF. In September of 2025 it was donated to the CNCF.

Key features.

Authentication for any web application without changing its code

Supports OAuth 2.0 and OpenID Connect providers

Designed to run simply in Kubernetes and beyond

Flexible authorization using email domains, groups, and claims

Multiple upstream applications behind a single proxy

Built and maintained in the open by its community
